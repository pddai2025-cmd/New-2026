# Project Pulse — контекст для Claude Code
Внутренний портал мониторинга инвестпроектов АО «Казахтелеком».
Полное задание: см. `ТЗ_Project_Pulse.md`. 

## Стек
Vite + React 18 + TypeScript. Стили — CSS-переменные/CSS Modules.
Графики — кастомные на Canvas (без тяжёлых библиотек).
MVP без бэкенда: данные в `src/data/projects.ts`.

## Команды
- `npm install`
- `npm run dev`    — локальная разработка
- `npm run build`  — статическая сборка в dist/
- `npm run test`   — unit-тесты бизнес-логики

## Правила
- Бизнес-логику (балл, статус, уровень риска) держать в `src/lib/` чистыми функциями + тесты.
- Не подключать localStorage для критичных данных, не добавлять бэкенд без отдельного решения.
- Сохранять фирменные токены: navy #0F1E3D, blue #007AC7, светофор green/amber/red.
- Шрифт Montserrat с системным фолбэком; приложение должно работать офлайн.
- Definition of Done — раздел «Критерии приёмки» в ТЗ.

## Порядок работ
Вести по фазам 1→6 из ТЗ. После каждой фазы — собирать и проверять по чек-листу приёмки.
